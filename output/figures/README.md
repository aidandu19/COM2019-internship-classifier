# Evaluation Figures

Each subfolder contains confusion matrices and reliability diagrams for one classification method, evaluated against 153 hand-labelled gold standard entries. The figures are generated by the evaluation pipeline in `src/evaluate.py` and provide a visual comparison of classifier performance across all three classification dimensions.

## Dimensions Measured

Every method is evaluated on three classification dimensions.

**firm_type** classifies the type of financial firm offering the internship. Categories include Bulge Bracket, Elite Boutique, Hedge Fund, Accounting, and others defined in the project taxonomy.

**role_function** classifies the job function the programme covers. Categories include Investment Banking, Markets & Trading, Quant, Consulting, and others.

**programme_status** classifies whether the application cycle is Open, Closed, or Not Yet Open.

## Chart Types

**Confusion matrices** show where predictions agree or disagree with gold standard labels. Cells on the diagonal represent correct classifications. Off-diagonal cells represent errors, with the row indicating the true label and the column indicating the predicted label.

**Reliability diagrams** plot stated confidence against actual accuracy across binned confidence ranges. Points falling on the diagonal indicate that the model's confidence matches its real-world accuracy. Points below the diagonal indicate overconfidence, where the model claims higher certainty than its accuracy warrants.
